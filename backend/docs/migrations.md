# Миграции в Docker

Сначала собрать и развернуть актуальный backend-образ с нужной веткой.
Изменений только во frontend недостаточно: код миграции должен находиться
внутри работающего контейнера `/app/dist/src/migrations/`.

Команды на сервере (из любого каталога):

```sh
docker exec -w /app platforma_backend npm run migration:show
docker exec -w /app platforma_backend npm run migration:run
docker restart platforma_backend
```

`[X]` означает выполненную миграцию, `[ ]` — ожидающую запуска.
TypeORM сам хранит историю в таблице `migrations`; повторный запуск не
повторяет выполненные миграции. `migration:run` выполняет все ожидающие
миграции в транзакции. Если команда завершилась с ошибкой, не переходить
к перезапуску: исправить указанную причину и повторить команду.

Для SEO событий нужна `AddEventSeo1792600000000`. Проверка наличия файла:

```sh
docker exec -w /app platforma_backend ls dist/src/migrations/1792600000000-AddEventSeo.js
```

Если файла нет — в контейнере ещё старый образ. Собрать и развернуть новый.
Все параметры подключения берутся из переменных окружения контейнера,
повторно указывать пароли в командах не нужно. CLI использует
`dist/typeorm.config.js`; автоматическая синхронизация схемы в нём отключена.

Раздельные картинки Telegram-баннера хранятся в JSON настроек сайта и
дополнительной SQL-миграции не требуют.
